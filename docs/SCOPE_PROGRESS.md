## 決定事項メモ

**2026-09-15 要件定義**

- 新特典の自動追加は **B案**（Claude Codeが `presents.js` に追記してpush）で確定。
  ページ側にAI・バックエンドは持たせない。
- サムネイルは **ハイブリッド方式** で確定。固有のヒーロー画像がある8本はそれを流用し、
  残りはタイトルからデザインを自動生成する。実物を生成して品質を確認済み。
  - 判断根拠: 14本のOGPを実測したところ、5本が『AIマネタイズの教科書』バナー共通で
    全て同じ絵になり、1本は画像なし。さらに旧・くすみブルー配色のページが混在するため、
    スクリーンショット流用だけでは一覧の見た目が揃わないことが判明した。
- カテゴリーは **テーマ軸の3つ** に統一（競合も同じ3分類）。
  当初案にあった「プロンプト集」は*形式*であり軸が混ざるため、カテゴリーから外して
  タグ側で表現する。軸が混ざると1件が複数カテゴリーに該当し絞り込みが破綻するため。
- リポジトリは新規作成する。既存の `instagram-tokuten-template` はテンプレート本体で
  あり編集しない方針（CLAUDE.md の規約）。

**2026-09-15 深掘りの決定（Step#10）**

- カードの並び順は **新着順のみ**。並べ替え機能・注目特典のピン留めは作らない。
- `type: "note"` のカードには「こちらの特典は外部サイト note に遷移します」の注釈を
  常時表示する（意図せぬ離脱を防ぐ）。GitHubページ型・プロンプト型には出さない。
- 既存14本の特典ページから、まとめページへ戻る導線を足す案は **不採用**。
- 旧・くすみブルー配色のページは **順次ピンクに寄せる**。ただし本プロジェクトの
  スコープ外とし、別タスクとして扱う（下記の別タスク欄を参照）。

**2026-09-15 掲載データ確定**

- 掲載対象は **全26件**（page 14 / note 11 / prompt 1）。noteは当初「約12本」の想定
  だったが実際は **11本**だった。
- 並び順は **種別グループ順 → グループ内新着順** に確定。note型とプロンプト型は
  最下部へ置く（自分のページを上に、外部へ離脱するnoteを下に）。
  当初の「純粋な新着順」から仕様を変更したもの。
- カード見出し（`title`）は長い元題を**短く言い換えてよい**。
  元題は `plainTitle` に全文を残し、検索対象にする（検索性を落とさないため）。
- カテゴリー分類の軸を **成果物軸** に確定。当初は「販売導線があるか」で分けていたが、
  それだと「LINEスタンプを作って販売する」が画像・動画づくりから外れ、画像を作りたい
  人が探す場所で見つからなくなるため。結果、件数も 11/9/6 に整った。
