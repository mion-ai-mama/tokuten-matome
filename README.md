# 特典まとめページ

Instagramで配布してきた特典を、1枚のページに集めたものです。

**公開URL**: https://mion-ai-mama.github.io/tokuten-matome/

---

## 1. いちばん大事なこと

**特典を追加・修正するときに触るのは `js/presents.js` だけです。**

このファイルに1件書き足せば、カード・カテゴリー別の件数・上部の総件数が
すべて自動で更新されます。`index.html` を手で編集する必要はありません
（編集すると二重管理になり、必ずどこかがズレます）。

---

## 2. 新しい特典を追加してもらうとき

Claude Codeに「**まとめに追加して**」と伝えるだけで大丈夫です。
コードを触る作業は発生しません。

AI側は次の手順で作業します。

1. 追加する特典のURLへ実際にアクセスして、開けることを確認する
2. `js/presents.js` の**その種別グループの先頭**に1件追記する
3. `number` は「いま使われている最大の番号 + 1」を付ける（既存の番号は変えない）
4. サムネイルを用意する（下記3参照）
5. `node tools/stamp-images.js` で画像の版番号を更新する
6. `node tools/validate.js` で検査を通す
7. ブラウザで表示を確認する
8. コミットしてpushする（数分後に公開ページへ反映されます）

---

## 3. サムネイルの考え方

| 特典の状況 | どうするか |
|---|---|
| 特典ページに専用のヒーロー画像がある | その画像を `assets/thumbs/` に入れて使う |
| note記事にアイキャッチがある | それを `assets/thumbs/` に入れて使う |
| どちらも無い | タイトルから自動生成する |

自動生成はこのコマンドで行います（無料・外部サービス不要）。

```bash
node tools/gen-thumb.js --missing   # 画像が無いものだけ作る
node tools/gen-thumb.js <特典のid>   # 1件だけ作り直す
node tools/gen-thumb.js --regen     # 自動生成ぶんをまとめて作り直す
```

> ⚠️ 自動生成の対象は `presents.js` で `thumbAuto: true` が付いた特典だけです。
> 写真やアイキャッチを使っている特典は、誤って上書きしないよう対象外にしてあります。

## 4. 表示の決まりごと

### 並び順

```
① 🎁 特典ページ（page）  … 新しい順   ← 一番上
② 📝 note               … 新しい順
③ 📋 プロンプト（prompt）           ← 一番下
```

自分のページを上に置き、外部サイトへ移動するnoteを下に置いています。
`presents.js` の配列の並びが、そのまま画面の並びになります。

新しい特典は「配列のいちばん上」ではなく「**その種別グループのいちばん上**」に
入れてください。

### 番号（number）の意味

番号は並び順とは別の軸で、**古い特典ほど小さく、新しい特典ほど大きく**なります。
そのため、下のほうにあるnote・プロンプトほど小さい番号です
（最初の26件は、ページを上から下に読むと 26 → 01 と減っていきます）。

番号はその特典に固定のIDです。新しい特典を足すときは「今の最大 + 1」を付けるだけで、
既存の番号は振り直しません。

### note特典の注釈

`type: "note"` のカードには「こちらの特典は外部サイト note に遷移します」が
自動で表示されます。特典ページ型・プロンプト型には表示されません。

### カテゴリーは3つだけ

- `ChatGPT・AI活用`
- `画像・動画づくり`
- `AIで副業・在宅ワーク`

「プロンプト集」「保存版」のような*形式*はカテゴリーではなく `tags` で表します。
軸を混ぜると1件が複数カテゴリーに当てはまり、絞り込みが壊れるためです。

## 6. ファイルの役割

| ファイル | 中身 |
|---|---|
| `index.html` | ページの骨組み |
| `css/style.css` | 色・レイアウト（色は先頭の `:root` を変えれば全体が変わります） |
| `js/presents.js` | **特典データ（唯一の真実の源）** |
| `js/script.js` | 絞り込み・検索・コピー機能 |
| `tools/gen-thumb.js` | サムネイル自動生成 |
| `tools/stamp-images.js` | 画像の版番号付け（差し替えを即座に反映させる） |
| `tools/validate.js` | 特典データの検査 |
| `assets/thumbs/` | サムネイル画像 |

---

## 7. 画像を差し替えたのに変わらないとき

ブラウザは一度読んだ画像をしばらく覚えているため、同じファイル名のまま中身だけ
差し替えると、古い画像が表示され続けます（最大10分）。

これを防ぐため、画像パスの末尾に `?v=` という版番号を付けています。
画像を差し替えたら必ず次を実行してください（中身が変わったものだけ更新されます）。

```bash
node tools/stamp-images.js
```

---

## 8. 公開について

`main` ブランチにpushすると、GitHub Pagesが数分で自動的に公開ページへ反映します。
特別な操作は必要ありません。
